# How to view or edit the documentation

You may find the editable final documentation in the airbus-ship-detection.docx file. It has applied formatting and is ready to be saved as pdf, the pdf in the folder is its direct copy and their content is guaranteed to be the same.

The airbus-ship-detection-non-formatted.docx contents is also the same as the two files' above, however, if you wish to edit the contents, it is significantly simpler to first edit there (unless you just wish to edit a simple typo), and then copy the text into the formatted final document. The reason why it is simpler is because the final document is subject to various formatting rules which is hard to keep in mind when writing accurate content.

The hungarian-title-and-abstract document has the hungarian title of the documentation and the abstracts' hungarian version.
